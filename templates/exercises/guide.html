Guide

Choisir un exercice

Les exercices sont classés par thème (« Thèmes » dans le menu). Chaque thème affiche sa progression — le nombre d'exercices déjà réussis — et se déplie sur la liste de ses exercices, chacun marqué comme réussi ou non.

Écrire et vérifier son code

Chaque exercice a son propre éditeur de code, pré-rempli avec l'en-tête de la fonction, et parfois une ou plusieurs fonctions utiles. Le bouton Vérifier exécute le code face à une série de tests : chaque ligne de résultat indique si le test correspondant est réussi ou non, avec un message expliquant ce qui était attendu.

Quand votre programme utilise print(), un menu « Ce qui a été affiché » permet d'en consulter les résultats.

Le code est enregistré automatiquement en quittant la page, et peut aussi être enregistré à la main à tout moment (bouton Enregistrer).

Lorsque tous les tests sont réussis, une proposition de correction est affichée. Celle-ci peut parfois sensiblement différer de votre réponse : ce n'est pas grave ! Prenez le temps de lire ces propositions qui peuvent être instructives.

Les indices

Quand des indices existent pour un exercice, un bouton Indice apparaît sous l'énoncé. Chaque clic révèle l'indice suivant, un par un.

Bloqué sur un exercice ?

Deux options, selon la situation :

Abandonner cet exercice affiche une proposition de solution complète. L'exercice reste alors verrouillé pendant 2h (pour éviter de « réciter » la solution vue précédemment).

Demander de l'aide à un professeur envoie le code actuel (avec un commentaire optionnel expliquant où ça bloque) à l'équipe de professeurs, sans verrouiller l'exercice. La réponse sera visible sur la page « Mes demandes d'aide ».

Suivre sa progression

La page « Progression » liste les exercices réussis, avec pour chacun le nombre d'indices utilisés, le nombre d'abandons et le temps passé dessus.
