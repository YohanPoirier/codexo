Qu'est-ce que le bac à sable ?

Le bac à sable est un espace libre pour essayer du code Python, sans exercice ni test associé. Écrivez ce que vous voulez, cliquez sur Exécuter, et observez le résultat : c'est l'endroit idéal pour tester une instruction, comprendre un message d'erreur ou vérifier une idée avant de l'utiliser dans un exercice.

Rien n'est corrigé ni comptabilisé dans votre progression. Le code n'est pas envoyé au serveur : il reste dans votre navigateur (et est simplement conservé sur cet appareil pour que vous le retrouviez à votre prochaine visite).

La fenêtre de résultat affiche uniquement ce qui a été écrit avec print(), ainsi que les éventuelles erreurs. Pensez donc à utiliser print() pour voir une valeur. Si la page se fige à cause d'une boucle infinie, rechargez-la.
