Le mode pas à pas

Le mode pas à pas permet de regarder un programme s'exécuter ligne par ligne, et de suivre l'évolution des variables à chaque étape. Il est utile pour comprendre ce que fait vraiment un code, ou pour trouver l'endroit où il ne fait pas ce qui était prévu.

  1. La ligne surlignée est celle qui vient d'être exécutée.
  2. L'appel du test qui est exécuté, sous le code. Un clic sur cette ligne permet de choisir un autre test.
  3. Avancer exécute la ligne suivante ; Reculer revient d'une étape en arrière.
  4. Un cadre par fonction en cours d'exécution, avec ses variables et leur valeur. Le cadre foncé est celui de la fonction qui s'exécute en ce moment ; le triangle ▼ le relie à la fonction qui l'a appelée.
  5. La console affiche ce que le programme écrit avec print(), la valeur renvoyée à la fin du test, et l'éventuelle erreur.

Quand une fonction en appelle une autre

  1. L'appel en cours est surligné…
  2. … ainsi que l'en-tête de la fonction appelée.
  3. Ses paramètres apparaissent dans un nouveau cadre. Les variables qui viennent d'être créées ou modifiées sont colorées.

Lancer le pas à pas

Sur la page d'un exercice, le bouton Pas à pas ouvre le code actuel de l'éditeur, même s'il n'a pas été enregistré.

Modifier le code

Le code peut être corrigé directement dans le pas à pas : le bouton Relancer le parcourt alors depuis le début. De retour sur l'exercice, la version modifiée est reprise dans l'éditeur.

Le pas à pas ne valide pas l'exercice : pour cela, il faut revenir à l'exercice et cliquer sur Vérifier.
